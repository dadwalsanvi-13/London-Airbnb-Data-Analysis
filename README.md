# London Airbnb Data Analysis

## MSc Business Analytics – University of Greenwich

### Project Overview
This project investigates Airbnb listings across Greater London using Python, computational thinking, and statistical analysis.

**Research question:** What drives Airbnb listing prices in London?

The dataset contains information about property types, nightly prices, neighbourhoods, host characteristics, guest reviews, and availability.

### Project Objectives
- Inspect and understand the dataset.
- Clean and prepare the data.
- Conduct exploratory data analysis.
- Investigate relationships between variables.
- Apply simple and multiple linear regression.
- Evaluate regression assumptions.
- Present findings and business insights.

### Main Findings (associations, not causes)
- Location (borough) and room type are the strongest drivers of price, followed by bedrooms and bathrooms.
- The final model explains about 63% of the variation in log price (adjusted R² 0.632).
